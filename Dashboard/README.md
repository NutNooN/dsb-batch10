# 🚛 Logistics Dashboard: Import-Export Operations

![Logistics Dashboard View](./Dashboard.jpg)

## 📊 Project Overview
This interactive Power BI dashboard visualizes the logistics performance of **Fruit Products Export/Import** from Thailand. It helps stakeholders monitor key metrics and optimize supply chain decisions.

### 🔑 Key Features
* **KPI Monitoring:** Tracks Total Profit (5.31M), Total Sales, and Shipment Counts.
* **Route Analysis:** Visualizes shipment routes from Thailand to global destinations (USA, Japan, etc.) using Map visualization.
* **Cost Breakdown:** Analyzes Inland, Freight, and Insurance costs to identify saving opportunities.
* **Product Performance:** Compares profitability across categories like Candied Fruit, Dried Fruit, and Fruit Paste.
